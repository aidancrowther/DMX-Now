# PCB files

This directory contains PCB design exports for the DMX Now receiver hardware:

- `1-Schematic_ESP DMX.json` — electrical schematic export.
- `1-PCB_PCB_ESP DMX.json` — PCB/layout export.

These files are design inputs/exports rather than a substitute for a fabrication
release package. Verify revision, design-rule status, footprints, drill data,
and manufacturing outputs before ordering boards.
